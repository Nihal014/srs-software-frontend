How to work out the stock value

close

The stock value is what the finished products you have made but not sold yet cost to make. Here is an example.

Step 1: Count what is left
At the end of the day, count the unsold products on the shelf: 12 samosas and 8 cutlets.
Step 2: Find what each one cost to make
Open Bundling, open the day, and read the Unit cost column of the runs table. It already includes ingredients, labour and overhead. Here: Samosa Snack Rs 5.55, Cutlet Rs 3.80.
Step 3: Multiply and add up
Product Count Unit cost Value
Samosa Snack 12 Rs 5.55 Rs 66.60
Cutlet 8 Rs 3.80 Rs 30.40
Total stock value Rs 97.00
Step 4: Record it
Click + Record value on this tab, enter today's date and 97.00, and save.
Remember
  • Use the unit cost, not the selling price. The selling price would count profit you have not earned yet.
  • If the same product was made on different days at different unit costs, use the cost of the run the leftovers came from. If you can't tell, the latest run's cost is a reasonable shortcut.
  • Count all unsold products from every day. The total is everything left, not only today's.
  • If everything is sold, record 0.
